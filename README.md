# SOLO Radar Free — Telegram

Бесплатный поиск **новых заголовков PoW-анонсов Bitcointalk** с отправкой уведомлений в Telegram. Проект использует GitHub Actions, без VPS и домашнего ПК.

## Подключение Telegram

1. Откройте [@solo_radar_hunter_bot](https://t.me/solo_radar_hunter_bot) в Telegram и нажмите **Start** (это обязательно, иначе бот не сможет присылать сообщения).
2. Узнайте свой личный числовой Telegram chat ID. Например, используйте Telegram-бота **@userinfobot**; убедитесь, что его данные выглядят как числовой ID. Не присылайте токен своего бота другим ботам или людям.
3. Откройте репозиторий → **Settings → Secrets and variables → Actions → New repository secret**.
4. Добавьте два секрета:
   - `TELEGRAM_BOT_TOKEN` — токен, полученный от BotFather.
   - `TELEGRAM_CHAT_ID` — ваш личный числовой chat ID.
5. Откройте вкладку **Actions → SOLO Radar — Telegram → Run workflow** (при необходимости сначала разрешите Actions).
6. После первого успешного запуска в Telegram придёт подтверждение подключения. Далее новые объявления проверяются по расписанию каждые 15 минут, но запуски GitHub иногда задерживаются.

## Что именно умеет версия 1

- Читает публичный раздел **Altcoin Announcements** форума Bitcointalk, когда он доступен с GitHub Actions.
- Ищет в заголовках признаки PoW, GPU, SOLO и mainnet.
- Отправляет только **новые** темы с достаточной оценкой заголовка.
- Помечает все находки как **НЕ ПРОВЕРЕНЫ**.
- Хранит только историю заголовков в `data/state.json`, чтобы не дублировать сигналы. Telegram chat ID и токен в публичные файлы не записываются.
- Первый запуск создаёт исходную базу и не рассылает старые анонсы.

**Ограничения:** нет мониторинга закрытого Discord, проверки блокчейна, прибыли, бирж и точного времени старта. Сбой доступа к Bitcointalk приведёт к пропущенным проверкам. Уведомления не означают рекомендацию начинать майнинг; перед запуском проверяйте официальный источник и безопасность бинарников.

На публичных репозиториях обычные GitHub Actions бесплатны, но правила и лимиты GitHub могут меняться. Для защиты доступа не размещайте токены в файлах или обсуждениях.
